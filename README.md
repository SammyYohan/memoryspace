# SPACE MEMORY — Les oubliés de l'espace

Prototype de jeu web éducatif et interactif consacré à l'exploration spatiale : enquête sur la mission Sojourner, globes 3D de la Lune et de Mars, fiche historique et musée des découvertes.

## Lancer le jeu

Ouvrir `space_memory_accueil_interactif.html` dans un navigateur récent.

Les pages 3D (`lune-3d.html`, `mars-3d.html`, `terre-lune-mars.html`) chargent Three.js r128 depuis un CDN : une connexion Internet est nécessaire.

## Pages

- `space_memory_accueil_interactif.html` — accueil et présentation
- `space_memory_profil.html` — profil ou mode invité
- `space_memory_carte.html` — choix de la destination
- `space_memory_mission.html` — briefing de la mission Sojourner
- `space_memory_enquete.html` — enquête interactive
- `space_memory_fiche.html` — fiche historique
- `space_memory_resultats.html` — récompenses
- `space_memory_musee.html` — collection et progression
- `lune-3d.html`, `mars-3d.html`, `terre-lune-mars.html` — expériences 3D
